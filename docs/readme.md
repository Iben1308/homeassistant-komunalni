# Панель "Комунальні" для Home Assistant створено з використанням Microsoft Copilot

## 🎯 Мета
Цей проєкт створений для організації та моніторингу всіх комунальних платежів у Home Assistant.  
Він дозволяє:
- Вести облік показників лічильників (світло, вода, газ).
- Вручну вводити абонплати (інтернет, телебачення, домофон, прибудинкова територія, вивіз сміття).
- Формувати місячну статистику витрат.
- Порівнювати витрати між місяцями (зростання/зменшення).
- Документувати конфігурацію та приклади використання для повторного застосування.

---

## 📋 Категорії моніторингу
- **Світло (електроенергія)** — лічильник, вартість.  
- **Вода** — холодна, гаряча, водовідведення (абонплата).  
- **Інтернет** — абонплата.  
- **Телебачення** — абонплата (за наявності).  
- **Газ** — лічильник, безлічильниковий тариф, доставка газу.  
- **Домофон** — абонплата.  
- **Прибудинкова територія** — абонплата.  
- **Вивіз сміття** — абонплата.  

---

## 🛠️ Реалізація
- **Input helpers** (`input_number`, `input_text`) для ручного введення платежів та показників.  
- **Utility meter** для автоматичного підрахунку місячних витрат.  
- **Template sensors** для порівняння витрат між місяцями.  
- **Lovelace Dashboard** з вкладкою "Комунальні":  
  - картки *Entities* для введення даних,  
  - картки *History-graph* для статистики,  
  - картки *Statistics-graph* для аналітики.

## 🚀 Використання
1. Скопіюйте файли у свою конфігурацію Home Assistant.  
2. Додайте сенсори у `configuration.yaml`.  
3. Перезапустіть Home Assistant.  
4. Відкрийте вкладку "Комунальні" у Lovelace.  
5. Вводьте показники та платежі вручну, переглядайте статистику по місяцях.  

---

## 🔧 Як додати новий платіж
1. Додайте `input_number` або `input_text` у `configuration.yaml`.  
2. Додайте його у відповідну секцію `ui-lovelace.yaml`.  
3. Перезапустіть Home Assistant.  
4. Новий платіж з’явиться у вкладці "Комунальні".
